# Tokona POS & ERP

Tokona is a modern, modular Point of Sale (POS) and Enterprise Resource Planning (ERP) application designed specifically to support SMEs (UMKM). Built with Clean Architecture, it handles core features like **Toko (Store)**, **Kasir (Cashier)**, and **Akuntan (Accountant)** efficiently.

## Live Demo
Experience the application in action:
**Live Demo:** [https://tokona-erp.onrender.com/login](https://tokona-erp.onrender.com/login)
*(Use the superadmin credentials to log in)*

## Tech Stack
- **Backend**: Laravel 11 (Controllers, Services, Form Requests, Eloquent UUID)
- **Frontend**: React 19, Inertia.js, Tailwind CSS v4
- **State Management**: Zustand
- **UI Components**: Shadcn UI & Radix UI
- **Data Tables**: `@tanstack/react-table`
- **Database**: PostgreSQL (Cloud/Neon DB ready)

## Key Features
Tokona is packed with enterprise-grade features tailored for retail and wholesale businesses:

- **Multi-Branch Management**: Manage multiple stores, warehouses, and branches from a single unified dashboard.
- **Canvas Sales App**: Empower your field sales (motoris/canvaser) with a dedicated mobile-friendly interface for on-the-go transactions.
- **Consignment (Barang Titipan)**: Easily track and manage consignment goods from external suppliers with accurate profit sharing and stock tracking.
- **Cashier Shift Management**: Track opening balances, closing cash, and sales performance per cashier shift to prevent fraud and discrepancies.
- **PPOB & Digital Products**: Built-in integration for selling digital products like phone credits (Pulsa), tokens, and bill payments.
- **Employee Attendance**: Integrated HRIS features to track employee check-ins and check-outs directly from the POS.
- **AI Shopee Importer**: Seamlessly import products using a Shopee URL! Integrated with Gemini AI, Tokona automatically extracts product details and intelligently auto-tags the correct categories and units.
- **Optimized Performance**: Lightning-fast sidebar rendering and navigation, perfectly optimized for Cloud Databases (like Neon Serverless Postgres) by eliminating N+1 query bottlenecks.
- **Unit of Measurement (UoM)**: Support for flexible product units (e.g., Pcs, Dus, Box, Kg) directly mapped during product creation and AI imports.
- **Expiration Date Tracking**: Easily monitor product shelf-life with our dynamic "Kedaluwarsa" badge that proactively warns cashiers about soon-to-expire or already expired items.
- **Advanced Barcode & QR Code**: Redesigned, highly-scannable Barcode and QR Code generation in the Product Detail sheet that flawlessly supports both 1D and 2D hardware cashier scanners.
- **POS Transaction Proofs**: Ability to capture, upload, and securely store transfer/payment proofs directly during active cashier transactions.

## Installation & Setup

Follow these instructions to set up the project locally on your machine.

### Prerequisites
- PHP 8.2 or higher
- Composer
- Node.js (v18+) & NPM
- PostgreSQL database

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/yourusername/tokona.git
cd tokona

# Install PHP dependencies
composer install

# Install Node.js dependencies
npm install
```

### 2. Environment Configuration
Copy the `.env.example` file to `.env`:
```bash
cp .env.example .env
```
Open the `.env` file and configure your database settings. For a local PostgreSQL setup:
```env
DB_CONNECTION=pgsql
DB_HOST=127.0.0.1
DB_PORT=5432
DB_DATABASE=your_database_name
DB_USERNAME=your_database_user
DB_PASSWORD=your_database_password
```
Generate the application key:
```bash
php artisan key:generate
```

### 3. Database Migration & Seeding
Ensure your local database is created, then run the migrations and seed the initial data (including the Super Admin account):
```bash
php artisan migrate:fresh --seed
```

### 4. Run the Development Server
You need to run two servers concurrently. 
Terminal 1 (Backend):
```bash
php artisan serve
```
Terminal 2 (Frontend/Vite):
```bash
npm run dev
```
Visit `http://localhost:8000` in your browser. You can log in using the credentials generated by the seeder (e.g., `superadmin@tokona.com`).

## Roadmap & Phases

### Phase 1 (Current Focus)
1. **Dashboard**: Overview, charts, top products, recent activities.
2. **POS (Kasir)**: Direct transactions, pending orders, refunds.
3. **Produk**: Master products, categories, UoM (Units), stock & inventory, expiration tracking, AI import.

## Directory Structure

### Frontend (`resources/js`)
We use a feature-based structure to keep the codebase organized as it scales:
```text
resources/js/
├── components/          # Shared UI components (Shadcn buttons, dialogs, etc.)
├── features/            # Feature-specific logic (e.g., pos, products, dashboard)
├── pages/               # Inertia page entry points (maps to Laravel routes)
├── store/               # Zustand global state stores
├── layouts/             # Dashboard and Auth layouts
└── lib/                 # Global utility functions (formatting, helpers)
```

### Backend (Laravel `app/`)
```text
app/
├── Http/
│   ├── Controllers/     # HTTP request handlers returning Inertia or JSON
│   ├── Requests/        # Form validation logic
│   └── Middleware/      # Custom middleware (e.g., HandleInertiaRequests)
├── Models/              # Eloquent models (using UUIDs)
└── Services/            # Business logic separation (Clean Architecture)
```
